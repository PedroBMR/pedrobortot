# QA Artifacts — Portfolio Evidence

## Propósito da pasta /qa
Esta pasta reúne artefatos de QA criados como **hands-on practice**, para demonstrar capacidade de:
- escrever casos de teste;
- registrar bugs com clareza;
- executar validações básicas de API (Postman);
- realizar verificações simples em SQL.

Todos os arquivos são **exemplos reutilizáveis** e usam placeholders quando necessário, sem inflar experiência.

## Como esses artefatos se conectam ao portfólio
Os arquivos aqui suportam os projetos do portfólio:
- **Portfolio QA** → `test-cases.md`, `bug-report.md`, `checklist-regression.md`
- **API Testing (basic)** → `api-test-cases.md`, `postman-collection.json`
- **SQL Checks (basic)** → `sql-checks.sql`, `sql-validations.md`

Eles funcionam como **documented evidence** e mostram organização e rastreabilidade de QA.

## Como adicionar um novo case de QA
1. Criar um novo arquivo de evidências (ex.: `qa/new-case-test-cases.md`).
2. Adicionar cenário, objetivo, escopo e resultados esperados.
3. Incluir referências em `README.md` para manter rastreabilidade.
4. Se houver API/SQL, criar coleções ou queries com validações básicas.

> Nota: use linguagem objetiva e indique o nível (básico/em prática).
